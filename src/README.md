# টাইপস্ক্রিপ্ট প্রবলেম সলভিং - অ্যাসাইনমেন্ট ১

টাইপ সেফটি, জেনেরিক্স (Generics), অবজেক্ট ওরিয়েন্টেড প্রোগ্রামিং (OOP) এবং অ্যাসিনক্রোনাস কোডের সহজ ও সংক্ষিপ্ত সমাধান।

---

## 🚀 সমাধানকৃত প্রবলেমসমূহ

| # | ফাংশন / ক্লাস | মূল কনসেপ্ট |
|---|---|---|
| **১** | `multiplyValue` | অপশনাল প্যারামিটার ও ডিফল্ট গুণক লজিক |
| **২** | `processInput` | টাইপ ন্যারোয়িং (Union Types: `string \| number \| boolean`) |
| **৩** | `formatCoordinate` | রিডঅনলি টাপল (Tuple) ডিস্ট্রাকচারিং ও ফরম্যাটিং |
| **৪** | `concatenateArrays` | জেনেরিক রেস্ট প্যারামিটার ও অ্যারে একত্র করা |
| **৫** | `getPopularCourses` | ইন্টারফেস টাইপিং ও কোর্স ফিল্টারিং |
| **৬** | `pluckValues` | জেনেরিক্স ও `keyof` ব্যবহার করে প্রপার্টির মান বের করা |
| **৭** | `Employee` ও `Manager` | OOP ইনহেরিটেন্স ও অ্যাক্সেস মডিফায়ার (`public`, `protected`, `private`) |
| **৮** | `validateAgeAsync` | `Promise` ব্যবহার করে অ্যাসিনক্রোনাস ভ্যালিডেশন |
